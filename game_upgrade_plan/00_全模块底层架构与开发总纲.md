## 🏗️ 当前主工程核心全局变量与数据接口规范

底层代码编写时，请严格遵守以下全局数据结构与命名规范，确保无缝嵌入主程序：

```javascript
/* 核心状态对象 (State Schema) */
state = {
  run: Boolean,           // 游戏运行状态
  wave: Number,          // 当前战区 (1~6)
  score: Number,         // 得分
  time: Number,          // 关卡倒计时 (秒)
  pending: Boolean,      // 波次准备状态
  tacticalPoints: Number,// 战术点数 (TP: 0~100)
  difficulty: String,    // 'easy' | 'normal' | 'hard'
  upgrades: []           // 已激活的 Roguelike 词条
};

/* 玩家实体对象 (Player Schema) */
player = {
  o: THREE.Group,        // 3D 根节点
  body: THREE.Mesh,      // 车体
  turret: THREE.Group,   // 炮塔
  recoilMesh: THREE.Group,// 后坐力节点
  hp: Number, maxHp: Number,
  energy: Number, maxEnergy: Number, // 歼灭风暴能量 (0~100)
  special: Number,       // 烟幕冷却 (秒)
  ammoType: String,      // 'normal' | 'apfsds' | 'he' | 'triple'
  ammoCount: Number      // 特殊弹药余量
};

/* 敌军与碰撞体结构 (Enemy & Collider Schema) */
colliders = [
  { x, z, w, d, hp: Number, maxHp: Number, isDestructible: Boolean, mesh: THREE.Mesh }
];
```

## 🚀 建议开发推进顺序

1. **第 1 阶段**：场景可破坏物理 & 履带印痕 (提升基础战场交互感)
2. **第 2 阶段**：战地电台语音与音效增强 (增强听觉临场沉浸感)
3. **第 3 阶段**：战术支援呼叫 1/2/3 键 & 友军 AI (丰富战斗操作维度)
4. **第 4 阶段**：波次结算 Roguelike 战车改装 & 勋章 (增加长期成长与策略)
5. **第 5 阶段**：第 6 战区终局巨型陆地要塞 BOSS 决战 (打造史诗级决战体验)
