# 模块六：动态天气风雪与夜战探照灯光影方案

- **文件绝对路径**：`d:\坦克大战\game_upgrade_plan\06_动态天气风雪与夜战探照灯方案.md`
- **模块职责**：暴风雪粒子场、动态昼夜环境光插值、坦克高强聚光大灯与高空战场照明弹。

---

## 🎯 模块设计目标
1. 战区之间拥有动态天气演变：
   - **Wave 1~2**：白昼风雪（能见度高）
   - **Wave 3~4**：黄昏暴雪（风速加大、雪花倾斜、车速微降）
   - **Wave 5~6**：极夜特战（环境光暗至 15%，依赖车前大灯与照明弹交火）
2. 坦克车前灯投射真实的**锥形光束 (SpotLight)**，照亮前方的敌军与掩体。

---

## 🛠️ 底层数据结构设计

```javascript
const weatherSystem = {
  currentEnv: 'day', // 'day' | 'dusk' | 'night'
  snowSpeed: { x: 3.5, y: -9.8, z: 2.0 },
  fogDensity: 0.015,
  nightLights: [],   // 夜间战场照明弹列表
  
  applyWaveWeather(wave) {
    if (wave <= 2) {
      this.currentEnv = 'day';
      dirLight.color.setHex(0xffffff);
      dirLight.intensity = 1.2;
      hemiLight.intensity = 0.8;
      scene.fog.color.setHex(0x1a2624);
      scene.fog.density = 0.012;
    } else if (wave <= 4) {
      this.currentEnv = 'dusk';
      dirLight.color.setHex(0xfda058); // 晚霞暖橙色
      dirLight.intensity = 0.85;
      hemiLight.intensity = 0.5;
      scene.fog.color.setHex(0x2a1c18);
      scene.fog.density = 0.020;
    } else {
      this.currentEnv = 'night';
      dirLight.color.setHex(0x384a68); // 幽蓝月光
      dirLight.intensity = 0.25;
      hemiLight.intensity = 0.15;
      scene.fog.color.setHex(0x060c10);
      scene.fog.density = 0.028;
    }
  }
};
```

## ⚙️ 核心逻辑流程

### 1. 战场高空照明弹 (Battlefield Flare)
```javascript
function launchBattlefieldFlare(x, z) {
  const flareLight = new THREE.PointLight(0xfff3d0, 5.0, 45, 1.2);
  flareLight.position.set(x, 22, z);
  scene.add(flareLight);
  
  weatherSystem.nightLights.push({
    light: flareLight,
    vy: -0.8, // 降落伞缓慢下坠
    life: 14.0
  });
}
```
