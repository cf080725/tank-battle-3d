## ⚙️ 核心逻辑流程与数学模型

### 1. 技能 1：火箭炮地毯覆盖 (Artillery Barrage Calculation)
```javascript
function triggerArtilleryBarrage(centerX, centerZ) {
  const skill = tacticalSupport.skills.artillery;
  let launched = 0;
  
  const barrageInterval = setInterval(() => {
    if (launched >= skill.shellsCount || !state.run) {
      clearInterval(barrageInterval);
      return;
    }
    launched++;
    // 在目标圆内随机分布弹着点
    const r = Math.random() * skill.radius;
    const theta = Math.random() * Math.PI * 2;
    const hitX = centerX + r * Math.cos(theta);
    const hitZ = centerZ + r * Math.sin(theta);
    
    // 生成从天而降的高抛弹道并产生范围伤害
    spawnAirDropShell(hitX, hitZ, skill.damagePerShell);
  }, 120);
}
```

### 2. 友军 AI 状态机 (Wingman Behavior Tree)
- **距离保持算法**：计算与玩家的距离 $D = \sqrt{(x_a - x_p)^2 + (z_a - z_p)^2}$
  - 若 $D > 16$ 米：切换为 `FOLLOW` 状态，全速向玩家斜后方 45° 编队点靠近；
  - 若 $6 \le D \le 16$ 米：搜索 $22$ 米内最近的敌军，切换为 `ENGAGE` 状态，旋转炮塔并射击；
  - 若友军 HP $< 25\%$：发射应急烟雾并退至玩家防线后方。
