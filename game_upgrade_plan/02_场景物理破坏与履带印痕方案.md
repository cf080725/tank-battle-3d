# 模块二：场景物理破坏与雪地履带印痕方案

## 🎯 模块设计目标
1. 让掩体（木屋、砖墙、水泥堡垒）具备生命值，被炮火击中时发生**阶段性碎裂**和**彻底坍塌**，动态改变掩护地形。
2. 坦克行驶时在雪原地面生成**实时履带轮印 (Tread Tracks)**，并在行驶数秒后逐渐淡化消散。
3. 坦克被摧毁时引发弹药架殉爆，炮塔翻滚炸飞至空中。

## 🛠️ 底层数据结构设计

### 1. 可破坏物体结构 (Destructible Obstacles)
```javascript
const destructibleObjects = [];

function createDestructibleWall(x, z, w, d, h, type = 'brick') {
  // type: 'brick' (红砖墙, hp: 4) | 'wood' (木屋, hp: 2) | 'bunker' (混凝土堡垒, hp: 8)
  const maxHp = type === 'wood' ? 2 : type === 'brick' ? 4 : 8;
  const obj = {
    x, z, w, d, h,
    type,
    hp: maxHp,
    maxHp: maxHp,
    mesh: null,          // 3D 渲染根节点
    isAlive: true
  };
  destructibleObjects.push(obj);
  return obj;
}
```

### 2. 雪地履带印痕管理器 (Tread Mark Trail System)
```javascript
const treadMarks = []; // 存储所有活跃的地面印痕片元
const MAX_TREAD_MARKS = 120; // 内存限制防卡顿

function addTreadMark(x, z, angle, width = 2.4, length = 0.8) {
  // 当坦克位移超过一定阈值 (如 0.6m) 时生成一对左右履带印痕
  if (treadMarks.length >= MAX_TREAD_MARKS) {
    const old = treadMarks.shift();
    scene.remove(old.mesh);
    old.mesh.geometry.dispose();
  }
  
  const geom = new THREE.PlaneGeometry(width, length);
  geom.rotateX(-Math.PI / 2);
  const mat = new THREE.MeshBasicMaterial({
    map: treadDecalTexture,
    transparent: true,
    opacity: 0.7,
    depthWrite: false
  });
  const plane = new THREE.Mesh(geom, mat);
  plane.position.set(x, 0.02, z);
  plane.rotation.y = angle;
  scene.add(plane);
  
  treadMarks.push({ mesh: plane, life: 12.0, maxLife: 12.0 });
}
```

## ⚙️ 核心逻辑流程

### 1. 炮弹命中掩体判定 (Bullet vs Wall Hit)
```javascript
function checkBulletDestruction(bullet, wall) {
  const isAP = bullet.ammoType === 'apfsds';
  const isHE = bullet.ammoType === 'he';
  const damage = isAP ? 3 : isHE ? 4 : 1;
  
  wall.hp -= damage;
  
  // 生成碎石/木屑物理飞溅碎片
  spawnDebrisCluster(bullet.x, 1.0, bullet.z, wall.type === 'wood' ? 'wood' : 'rock', 8);
  
  if (wall.hp <= 0) {
    // 掩体彻底崩塌
    wall.isAlive = false;
    scene.remove(wall.mesh);
    // 从常规移动阻挡列表 (colliders) 中移除，坦克和炮弹可通过
    removeColliderByMesh(wall.mesh);
    // 播放大爆炸与烟尘
    soundEngine.playExplosion(true);
    spawnSmokePuff(wall.x, wall.z, 2.5);
  } else {
    // 掩体进入破损形态（表面附加焦黑裂纹贴图或轻微下陷）
    wall.mesh.scale.y = Math.max(0.3, wall.hp / wall.maxHp);
  }
}
```

### 2. 炮塔炸飞物理 (Turret Pop-off)
```javascript
const flyingTurrets = [];

function spawnFlyingTurret(tankGroup, turretGroup) {
  // 复制炮塔几何体并脱离底盘
  const flying = turretGroup.clone();
  flying.position.copy(tankGroup.position);
  flying.position.y += 1.2;
  scene.add(flying);
  
  flyingTurrets.push({
    mesh: flying,
    vel: new THREE.Vector3((Math.random() - 0.5) * 4, 8 + Math.random() * 4, (Math.random() - 0.5) * 4),
    rotVel: new THREE.Vector3(Math.random() * 8, Math.random() * 8, Math.random() * 8),
    life: 4.0
  });
}
```
