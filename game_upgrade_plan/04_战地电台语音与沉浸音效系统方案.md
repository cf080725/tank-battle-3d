## 🎯 模块设计目标
1. 使用浏览器原生语音合成能力（无需外挂任何第三方音视频大文件），配合 Web Audio 的**带通无线电滤波（Bandpass Filter）+ 白噪声底噪**，拟真出装甲战车对讲机的真实无线电通话质感；
2. 在击穿、跳弹、击毁、受创、大招就绪、战役胜利等关键时刻触发军旅风格热血语音。

## ⚙️ 核心逻辑流程与音频处理链

### 1. 拟真电台声音合成器 (Radio Audio Pipeline)
```javascript
class RadioVoiceEngine {
  constructor(audioCtx) {
    this.ctx = audioCtx;
    this.synth = window.speechSynthesis;
    this.isSpeaking = false;
  }

  playRadioBeep() {
    // 播放对讲机开麦/闭麦的短促 "哔——喀" 机械高频音
    if (!this.ctx) return;
    const osc = this.ctx.createOscillator();
    const gain = this.ctx.createGain();
    osc.frequency.setValueAtTime(1800, this.ctx.currentTime);
    gain.gain.setValueAtTime(0.12, this.ctx.currentTime);
    gain.gain.exponentialRampToValueAtTime(0.001, this.ctx.currentTime + 0.08);
    osc.connect(gain);
    gain.connect(this.ctx.destination);
    osc.start();
    osc.stop(this.ctx.currentTime + 0.08);
  }

  speak(textGroup) {
    if (!this.synth) return;
    const list = radioVoiceEvents[textGroup];
    if (!list || list.length === 0) return;
    
    // 随机挑选一句语音
    const text = list[Math.floor(Math.random() * list.length)];
    
    // 播放开麦提示音
    this.playRadioBeep();
    
    const utter = new SpeechSynthesisUtterance(text);
    utter.lang = 'zh-CN';
    utter.rate = 1.15; // 稍快的战场紧急军语语速
    utter.pitch = 0.95; // 沉稳有力的低音车长声调
    
    utter.onend = () => {
      this.playRadioBeep(); // 闭麦音
    };
    
    this.synth.cancel(); // 避免队列积压
    this.synth.speak(utter);
  }
}
```
