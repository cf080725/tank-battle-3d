## 🎯 动态柴油引擎合成算法（Procedural Diesel Engine）

通过 Web Audio API 构建双振荡器 + 动态低通滤波器的实时柴油机声学模型：

```javascript
class EngineSoundSynthesizer {
  constructor(audioCtx) {
    this.ctx = audioCtx;
    this.osc1 = null;
    this.osc2 = null;
    this.filter = null;
    this.gain = null;
    this.isRunning = false;
  }
  start() {
    if (this.isRunning || !this.ctx) return;
    const t = this.ctx.currentTime;
    
    // 主缸低频脉冲 (40Hz ~ 110Hz)
    this.osc1 = this.ctx.createOscillator();
    this.osc1.type = 'sawtooth';
    this.osc1.frequency.setValueAtTime(42, t);

    // 谐波振荡器
    this.osc2 = this.ctx.createOscillator();
    this.osc2.type = 'triangle';
    this.osc2.frequency.setValueAtTime(84, t);

    this.filter = this.ctx.createBiquadFilter();
    this.filter.type = 'lowpass';
    this.filter.frequency.setValueAtTime(160, t);

    this.gain = this.ctx.createGain();
    this.gain.gain.setValueAtTime(0.22, t);

    this.osc1.connect(this.filter);
    this.osc2.connect(this.filter);
    this.filter.connect(this.gain);
    this.gain.connect(this.ctx.destination);

    this.osc1.start(t);
    this.osc2.start(t);
    this.isRunning = true;
  }
  update(speedRatio, isTurning) {
    if (!this.isRunning) return;
    const t = this.ctx.currentTime;
    // 随油门/转速动态提升基频与截止频率
    const targetFreq = 42 + speedRatio * 58 + (isTurning ? 12 : 0);
    const targetCutoff = 160 + speedRatio * 320;
    const targetGain = 0.20 + speedRatio * 0.25;

    this.osc1.frequency.setTargetAtTime(targetFreq, t, 0.08);
    this.osc2.frequency.setTargetAtTime(targetFreq * 2, t, 0.08);
    this.filter.frequency.setTargetAtTime(targetCutoff, t, 0.08);
    this.gain.gain.setTargetAtTime(targetGain, t, 0.08);
  }
}
```

## 🎵 战场环境动态音景（Dynamic Soundscape）
1. **远景炮火低吼（Distant Artillery Loops）**：每隔 6~14 秒在后台随机生成极低频沉闷雷鸣声；
2. **履带挤压积雪音**：行进转向时叠加白噪声滤波产生的高频沙沙声。
