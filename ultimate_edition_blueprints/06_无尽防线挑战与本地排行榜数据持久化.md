## 🎯 无尽防线波次算法（Endless Wave Generator）

当玩家通关第 6 波战役并击败利维坦后，解锁「无尽防线 (Endless Defense)」模式：
- **波次难度递推公式**：
  $$\text{EnemyCount} = 6 + \lfloor \text{Wave} \times 1.8 \rfloor$$
  $$\text{EnemyHP\_Scale} = 1.0 + (\text{Wave} - 6) \times 0.15$$
  $$\text{EnemySpeed\_Scale} = \min(1.5, 1.0 + (\text{Wave} - 6) \times 0.04)$$
- **精英与特种敌车概率**：
  - 波次越高，重装突击坦克、自行火箭炮车、隐身侦察车的生成概率指数级上升。

## 💾 LocalStorage 结构与排行榜管理器

```javascript
const LeaderboardSystem = {
  STORAGE_KEY: 'tank_battle_records_v1',
  getRecords() {
    try {
      const data = localStorage.getItem(this.STORAGE_KEY);
      return data ? JSON.parse(data) : [];
    } catch(e) { return []; }
  },
  saveRunRecord(record) {
    const records = this.getRecords();
    records.push({
      date: new Date().toISOString(),
      score: record.score,
      wave: record.wave,
      kills: record.kills,
      accuracy: record.accuracy,
      flawless: record.flawless,
      time: record.time
    });
    // 按得分由高到低排序，保留前 10 最佳战绩
    records.sort((a, b) => b.score - a.score);
    const top10 = records.slice(0, 10);
    try {
      localStorage.setItem(this.STORAGE_KEY, JSON.stringify(top10));
    } catch(e) {}
    return top10;
  }
};
```
