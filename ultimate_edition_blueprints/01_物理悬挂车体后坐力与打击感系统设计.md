# 模块一：物理悬挂、车体后坐力俯仰与触觉反馈系统

---

## 🎯 功能设计规格

### 1. 战车底盘物理俯仰（Recoil & Braking Pitch）
- **开火后坐力（Recoil Kick）**：
  - 开火瞬间赋予战车车体一个反向俯仰角冲量：`pitchVelocity -= recoilForce`（重炮约为 `0.12 rad`，臼炮为 `0.22 rad`）；
  - 使用阻尼弹簧振子模型平滑复位：
    $$\text{pitchAcc} = -k \cdot \text{pitch} - c \cdot \text{pitchVel}$$
- **加速与制动俯仰（Acceleration & Braking Squat/Dive）**：
  - 急加速时车尾下沉（Squat）、急刹车时车头下沉（Nosedive），提升底盘重量感。
- **履带悬挂颠簸（Suspension Bump）**：
  - 行进时根据速度叠加高频随机微晃动，模拟雪地坑洼颠簸。

### 2. 弱点击穿与暴击反馈系统（Armor Penetration & Crit）
- **装甲弱点判定**：
  - 正面装甲：伤害倍率 `1.0x`，普通火花；
  - 侧面装甲：伤害倍率 `1.35x`；
  - 尾部发动机舱 / 炮塔座圈接缝：伤害倍率 `2.0x`（暴击 Crit）；
- **暴击视觉与音频表现**：
  - 弹出金色暴击伤害跳字与强化命中准星；
  - 产生高密度金色穿甲火星飞溅与清脆破甲金属撕裂音。

### 3. 多级触觉马达振动引擎（Haptic Feedback Engine）
```javascript
const HapticEngine = {
  enabled: 'vibrate' in navigator,
  trigger(type) {
    if (!this.enabled) return;
    try {
      switch (type) {
        case 'fire_light':   navigator.vibrate(12); break;
        case 'fire_heavy':   navigator.vibrate(28); break;
        case 'hit_damage':   navigator.vibrate([20, 15, 35]); break;
        case 'crit_strike':  navigator.vibrate([15, 10, 50]); break;
        case 'ultimate_boom': navigator.vibrate([60, 30, 80, 40, 120]); break;
        case 'button_tap':   navigator.vibrate(8); break;
      }
    } catch(e) {}
  }
};
```
